# v0.1.0 — Initial Release

> Draft release notes. Intended Git tag: `v0.1.0`.

Rust/PyO3 ETF 形态匹配计算核心，与 C++/pybind11 原版的核心 Python API 和数值行为兼容。

## Highlights

- DTW（Sakoe-Chiba band）、余弦相似度、序列标准化与 15 维形态匹配引擎。
- 31 个冻结 golden fixtures 全部通过，与 C++ 原版在约定容差内一致。
- rayon 并行批量匹配；16 线程路径相对 Rust 单线程约 5.33× 自身加速。
- 可选 Panel 适配器与 FastMCP server，核心导入不要求 Torch/FastMCP。
- NRR-2026-023 提供 C++/pybind11 与 Rust/PyO3 的预登记性能对比及原始数据。
- Windows MSVC + Python 3.12 CI，包含 fmt、clippy、Rust/Python 测试、wheel 构建、内容门禁与安装后 smoke test。

## 安装

```bash
pip install etf-pattern-match-pyo3
```

可选功能：

```bash
pip install "etf-pattern-match-pyo3[panel]"
pip install "etf-pattern-match-pyo3[mcp]"
```
